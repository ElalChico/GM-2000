## 📌 Descripción

GM2000 es un sistema de entrenamiento de ajedrez diseñado específicamente para jugadores intermedios y avanzados. Esta aplicación se enfoca en el análisis profundo de posiciones, entrenamiento táctico especializado y simulación de escenarios de juego real con control de tiempo preciso.

## ✨ Características Técnicas

- **Tablero interactivo** con animaciones fluidas y rotación automática
- **Modos de juego especializados**:
  - Modo Entrenamiento personalizable (configura tus piezas y las del oponente)
  - Modo Libre para análisis de posiciones sin restricciones
  - Dos modos de freestyle
  - Piezas invisibles (para entrenamiento de memoria
  - Partidas con cronómetro (Bullet, Blitz, Rapid)
- **Sistema de análisis visual**:
  - Detección de jaque en tiempo real
  - Visualización de movimientos legales
  - Alertas de piezas atacadas
- **Herramientas de análisis**:
  - Gráficos de evaluación de material durante partidas
  - Estadísticas de victorias por color
  - Registro completo de movimientos en formato PGN
- **Personalización avanzada**:
  - Colores de casillas personalizables
  - Velocidad de animación ajustable
  - Coordenadas en el tablero
  - Sonidos específicos por tipo de movimiento (capturas, enroques, jaques)
- **Funcionalidades profesionales**:
  - Sistema de deshacer/rehacer movimientos
  - Guardado y carga de partidas
  - Análisis estadístico persistente entre sesiones

## 🚀 Cómo Usar
0. **Instalación: .EXE (disponible en https://mega.nz/file/SXJRRCzZ#G_hXm8kTdWG9OxglpPL0LnJU5bZZQ3fgrHJlJ96A9qs (MEGA) Descomprimir, ejecutar el setup, seguir los pasos de instalacion y listo.
1. **Versión Web**: 
   - Visita el enlace de la aplicación online
   - No requiere instalación ni registro

2. **Controles Básicos**:
   - Click en piezas para seleccionar
   - Click en casillas válidas para mover
   - Botón "INICIAR SISTEMA" para comenzar partidas con tiempo
   - Botón "⚙ AJUSTES" para acceder a la configuración avanzada

3. **Modos Especializados**:
   - **Entrenamiento**: Configura piezas específicas para practicar finales o tácticas complejas
   - **Modo Libre**: Permite mover cualquier pieza en cualquier momento para análisis de posiciones
   - **Análisis de tiempo**: Practica con diferentes controles de tiempo para simular torneos
